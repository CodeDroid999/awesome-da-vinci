# The Room as a Neural Network

Each figure functions as a node inside a distributed processing system where meaning is not stored in one place, but emerges through interaction.

# Neural Network Structure Before Machines

Modern neural networks consist of:
- nodes (neurons)
- weighted connections
- activation functions
- signal propagation
- layered interpretation
- emergent output behavior

Leonardo constructs a structurally analogous system centuries before formal computation.

Instead of silicon:
- human bodies are nodes  
Instead of weights:
- relationships define signal strength  
Instead of activation functions:
- emotion determines output  
Instead of training data:
- shared cultural memory acts as prior distribution  

The painting becomes a biological-computational hybrid system.

# The Input Signal: A Semantic Shock

Every neural system begins with an input.

In the painting, the input is linguistic:

> “One of you will betray me.”

This statement acts as:
- a semantic trigger

- a destabilizing feature injection into a trained relational system

Before this moment:
- trust is stable  
- relationships are normalized  
- identity is assumed  
- social weights are balanced

- all internal weights begin updating simultaneously  

The system enters full-scale re-evaluation.

# Backpropagation of Betrayal

In neural networks, errors propagate backward to adjust internal weights.

The announcement of betrayal triggers a similar phenomenon:

1. input received (“betrayal exists in the system”)
2. error detected (trust assumption violated)
3. backward propagation begins
4. internal relationship models update
5. identity reassessment occurs
6. social network reconfigures

Each disciple performs internal backpropagation:
- “What does this mean about me?”
- “What does this mean about others?”
- “Where do I sit in the trust graph?”

The system learns in real time.

But the learning is destabilizing.

# Overfitting to Trust

Neural systems fail when they overfit—when they assume patterns are stable beyond their validity.

The disciples exist in a condition of social overfitting:
- they assumed relational stability
- they encoded trust as fixed structure
- they treated group cohesion as invariant

The betrayal input breaks this assumption.

The system must generalize beyond its training:
- trust is not absolute
- identity is not fixed
- proximity does not guarantee loyalty

This realization creates cognitive rupture.
