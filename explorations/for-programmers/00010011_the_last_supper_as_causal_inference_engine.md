
# The Last Supper as a Causal Inference Engine

## Reality as a System That Infers Why Things Happen

Under classical interpretation, :contentReference[oaicite:0]{index=0} depicts a moment of revelation: betrayal announced within a sacred gathering.

Under computational reasoning, it operates as a **causal inference engine**—a system designed to infer hidden causes from observable effects under uncertainty.

The painting is not a representation of an event.

It is a machine for reasoning about why the event is happening.

---

# Causal Model Structure

A causal inference system contains:

- latent variables (hidden causes)
- observed variables (visible effects)
- probabilistic dependencies
- conditional likelihoods
- hypothesis updates

In this model:

- betrayal = latent cause
- gestures/emotions = observed effects
- disciples = inference nodes
- viewer = inference executor

The system attempts to reconstruct invisible causality from visible expression.

---

# Observations: The Evidence Layer

After the statement:

> “One of you will betray me”

the system produces observable evidence:

- facial tension
- gaze shifts
- defensive gestures
- emotional fragmentation
- relational repositioning

These are not causes.

They are **effect signatures**.

The painting is entirely composed of these signatures.
